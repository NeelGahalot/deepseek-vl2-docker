# Run the DeepSeek-VL2-Tiny model effortlessly with Docker

This repo provides a minimal Dockerfile to run [DeepSeek-VL2-Tiny](https://github.com/deepseek-ai/DeepSeek-VL2) without setup headaches. Ideal for quick experimentation and deployments. 

Make sure to run with the --gpus all tag, even the tiny version would need an L4 gpu instance to run.
